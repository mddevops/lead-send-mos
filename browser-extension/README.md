# Lead Send Form Mapper (Chrome / Edge)

Расширение для ручного захвата CSS-селекторов форм и импорта в project `lead-send`.

## Установка

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите **Developer mode**.
3. **Load unpacked** → выберите папку `browser-extension`.
4. Откройте popup расширения → ⚙ → проверьте destination:
   - Base URL: `http://127.0.0.1:8000` (без `/api`)
   - Token: значение `BOT_API_TOKEN` из `.env`
5. Нажмите **Проверить / загрузить регионы**.

## Захват формы на сайте

1. Откройте нужный сайт / страницу с формой.
2. После Reload расширения нажмите **F5** на вкладке (или дождитесь авто-reinject) — в панели должно быть **Form Mapper v1.3.0**.
3. Нажмите **Alt+Space** (запасной: **Alt+Shift+M**) — панель Form Mapper.
4. Кликайте элементы по ролям:
   - **Открыть модалку** (опц.)
   - **Шаг квиза** (опц., можно несколько)
   - **Телефон**
   - **Имя (отдельное)** / **Фамилия (отдельное)** — если поля раздельные
   - **ФИО (одно поле)** — если одно поле имени
   - **Email** (опц.)
   - **Select (рандом)** — дилер/модель/город; можно несколько
   - **Submit**, **Чекбокс 1/2**, **Success**
   - **Шаг квиза** — для chat/quiz воронок (модель → комплектация → подарок → форма). Каждый клик сохраняется и сразу выполняется; после появления формы переключитесь на Телефон.
   - **Чекбокс 1 / Чекбокс 2** — отдельные согласия. Кликайте сам input или его label, не общий контейнер с обоими.
   - Если второго чекбокса / квиза / select нет — **Пропустить роль**.
   - **Alt+клик** — обычный клик по сайту (открыть модалку), без захвата селектора.
   - Роль «Открыть модалку»: после клика селектор сохраняется и кнопка нажимается сама.
   - После клика на телефон/имя расширение само ставит `form_scope` = ближайшая `<form>`.
   - Submit и инпуты сохраняются **относительно этой формы**.
5. Для success:
   - выберите роль **Success** и кликните блок «Спасибо», или
   - нажмите **Watch success**, отправьте форму вручную — расширение поймает модалку / редирект.
6. Нажмите **Сохранить форму**. Если была ошибка sendMessage — обновите страницу (F5) после Reload расширения.
7. В popup у шаблона формы вставьте список URL → **Сохранить страницы**.

## Popup

- Список сайтов и форм.
- Регион на сайт или массово: отметьте сайты → выберите регион → **Применить**.
- **Очистить** — выбранные или все.
- ⚙ — несколько API destinations.
- **Отправить по API ▾** — выбрать destination и импортировать (сайты создаются автоматически).

## API (Laravel)

- `GET /api/bot/extension/meta`
- `POST /api/bot/extension/import`

Auth: `Authorization: Bearer {BOT_API_TOKEN}`.
